# 프로젝트 스크린샷

T01 소개 페이지에서 사용하는 공개용 프로젝트 스크린샷을 보관하는 폴더입니다.

## 권장 파일명

- `stock-service.webp`
- `omnidroid.webp`
- `wipirevive.webp`
- `web-restoration.webp`

## 추가 전 확인

1. 내가 만든 UI·도구·코드 실행 결과를 우선 사용합니다.
2. 계정명, 이메일, 로컬 경로, 토큰, API Key, IP 등은 가립니다.
3. 타사 캐릭터·로고·게임 화면·에셋은 꼭 필요한 범위만 남깁니다.
4. 공개 가능 여부가 애매하면 페이지에는 넣지 않습니다.
5. 원본 자료나 다운로드 링크 대신 결과 화면을 설명하는 용도로 사용합니다.

스크린샷이 준비되면 `index.html`의 각 `.preview-placeholder`를 `<img>`로 교체합니다.
