T07 · PUBLIC EVIDENCE / VERIFIED RETROSPECTIVE

기억을 꾸미지 않고,
기록으로 설명하는 5일.

개발 저장소에 실제로 남아 있는 커밋 SHA와 UTC 시각을 KST 날짜로 변환해 검증합니다. 실사용 시간이나 근거 없는 일기 문장은 만들어 내지 않습니다.

과제 채점상 중요한 구분

이 페이지는 과거 서로 다른 날짜 5일의 실제 공개 Git 활동을 오늘 소급 정리한 회고입니다. T07 인증 앱을 그 과거 5일 동안 사용했다는 증거가 아니며, 2일차 뒤 3일차 전 당시에 계획 규칙을 변경했다는 증거도 아닙니다. 해당 두 항목은 별도 미충족으로 명시합니다.

날짜별 근거 링크

커밋 수는 선택한 공개 저장소 3개의 해당 날짜 커밋 수를 더한 것입니다. 커밋 수 = 실제 근무 시간이 아닙니다.

GitHub 원본으로부터 저장한 근거 데이터를 불러오는 중…

REPRODUCIBLE CALCULATION

같은 계산 공식으로 검산

날짜(c) = Asia/Seoul 기준 date(commit.committer.date)
일별 커밋 수(d) = COUNT(DISTINCT (repository, SHA)) WHERE 날짜(c) = d
총합 = Σ(일별 커밋 수)
5일 평균 = ROUND(총합 / 5, 소수 첫째 자리)
앞의 2일 평균 = ROUND((1일차 + 2일차) / 2, 소수 첫째 자리)
뒤의 3일 평균 = ROUND((3일차 + 4일차 + 5일차) / 3, 소수 첫째 자리)

비교값은 기술 통계일 뿐, 특정 계획 규칙 변경의 효과로 해석하지 않습니다. 서로 떨어진 날짜를 사후 선택했다는 한계도 공개합니다.
