01 · IDENTITY

비밀번호 없는 입장

잠금 상태

기기 내 Windows Hello · Touch ID · Google 비밀번호 관리자 · 보안 키 등이 패스키 저장을 지원합니다. 인증용 기기 PIN·생체정보는 이 서버로 전달되지 않습니다.

처음 사용하는 경우 새 공간을 만드세요. 별도 이메일·비밀번호 계정은 필요 없습니다. 두 번째 계정 검사는 다른 브라우저 프로필에서 새 공간을 만들어 진행할 수 있습니다.

기기의 패스키 서명을 서버가 확인했습니다. 아래 세 가지 **과제용 가상 메모**는 로그인 성공 뒤에만 서버에서 받아 표시합니다.

02 · PROTECTED RESOURCE

비공개 자료

인증 필요
◇

자료가 잠겨 있습니다.

비로그인 상태에서는 내용을 표시하지 않으며, 실제 서버 요청도 HTTP 401로 거절됩니다. 이 페이지의 HTML·JavaScript에도 비공개 메모 원문이 포함되지 않습니다.

아래 내용은 모두 만들어 넣은 예시이며, 실제 개인정보·연락처·신분증 정보가 아닙니다.

03 · ACCOUNT RECOVERY

내 패스키 관리

복수 등록 권장

두 번째 패스키를 다른 기기나 다른 비밀번호 관리자에 저장해 분실에 대비하세요. 패스키가 하나만 남으면 마지막 패스키 삭제를 차단합니다. 완전히 잃어버리면 비밀번호 복구 기능이 없어 기존 공간에 접근할 수 없습니다.

서버가 보관한 공개키란?

서버에는 COSE 형식의 공개키와 서명 횟수 카운터 등이 저장됩니다. 아래 목록에서 공개키 앞부분을 확인할 수 있습니다. 개인키는 저장되지 않습니다.

보안 검증 결과는 인증 구현 설명서에서 확인합니다.
