## 실무 및 현장 경험

- **PC 설치·환경 설정:** 은행 업무용 Windows PC 설치와 초기 환경 구성 관련 업무 경험. 현장 사용자에게 필요한 설정·설치 순서를 확인했습니다. (경력 기간·직책은 지원 시 공식 경력증빙을 기준으로 기재)
- **행정·민원 지원:** 행정 지원 및 민원 응대 관련 업무 경험. 서류·안내사항을 확인하고 상대가 다음 절차를 이해하도록 설명하는 과정을 경험했습니다. (기관별 세부 기간은 증빙 확인 후 기재)
- **개발 교육과 프로젝트:** 2026년 8월~10월, 개발 교육 중 웹·데이터·보안·재현 실험 관련 과제를 작성했습니다. 아래 공개 프로젝트와 문서로 구현 범위를 확인할 수 있습니다.

## 기술 및 학습 분야

- **Backend / Web:** Java, Spring Boot, Spring Security, Python, JavaScript, Flask 기초·응용
- **Data / DB:** PostgreSQL, MySQL, SQL, Supabase
- **Frontend:** HTML/CSS/JavaScript, React 학습 및 웹 UI 제작
- **Tools:** Git/GitHub, Vercel, Postman, VS Code, IntelliJ
- **검증:** HTTP 응답 검사, 서버 접근 제어 점검, 단위·재현 검증, 실험 원자료 관리

위 항목은 학습과 사용 경험을 나타내며 상용 환경의 숙련도를 보증하지 않습니다.
