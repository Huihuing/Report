## 1. 한 줄 소개
냉장고에 남은 식재료를 입력하면 만들기 좋은 요리를 추천하고 부족한 재료와 단계별 조리 설명까지 안내하는 웹앱.

## 2. 대상 사용자
자취생, 요리를 처음 시작하는 사람, 냉장고 속 남은 재료를 효율적으로 활용하고 싶은 일반 사용자.

## 3. 핵심 기능 — 3개 유지
1. **식재료 관리:** 재료 추가·삭제, 중복 방지 및 별칭 정규화(계란/달걀), 브라우저 로컬 저장.
2. **맞춤 요리 추천:** 정적 예시 레시피 32개와 재료를 비교하고 일치도순으로 정렬, 요리 검색·필터.
3. **부족 재료 + 조리 안내:** 요리별 보유/부족 재료 구분, 기본 재료 충족 표시, 요리 카드에서 **단계별 상세 조리법 펼쳐 보기**.

## 4. v1에서 수정된 점과 이유
- **변경 요청:** 기존 한 줄 조리 팁만으로는 실제 요리를 따라 하기 어려우므로 단계별 조리 방법이 필요하다는 후속 개선 요청을 반영한다.
- **범위 조정:** 원래 3번째 핵심 기능(부족 재료 안내)을 유지하며, 그 결과를 활용할 수 있도록 단계별 설명을 추가했다. 별도의 4번째 핵심 기능으로 확대하지 않는다.
- **실행 방식:** 32개 모든 레시피에 최소 3개의 단계별 조리 안내를 추가하고, 요리 카드의 \`<details><summary>\`를 이용해 필요할 때만 펼쳐 볼 수 있도록 설계했다.
- **기록 원칙:** 이 변경 요청은 프로젝트 진행 중 제안된 개선 항목이며, 실제 외부 사용자가 직접 남긴 후기 또는 인터뷰가 아님. 사용자 피드백을 받았다고 허위로 표기하지 않는다.
- **안전 안내:** 단계별 조리법은 요약 예시이므로 음식 위생·충분한 익힘·알레르기·양념·정확한 수량을 사용자에게 안내한다.

## 5. 검증 가능한 완료 기준
1. 32개 레시피의 ID와 이름이 중복되지 않는다.
2. 32개 레시피 모두 3단계 이상 조리 설명이 포함된다.
3. 버튼/키보드로 요리 카드별 단계별 조리법을 열고 닫을 수 있다.
4. 보유 재료 2개(밥·계란) 입력 시 간장계란밥 기본 재료 일치도 100%로 계산된다.
5. 계란 삭제 시 부족한 기본 재료로 달걀이 표시된다.
6. 빈 재료명/중복/부적절한 입력을 거부하고 오류 안내를 표시한다.
7. 재료 목록은 새로고침 후에도 동일 브라우저에 남는다.
8. 반응형 레이아웃에서 조리법이 다른 UI와 겹치지 않는다.
9. 공개 페이지는 회원가입 없이 접근 가능해야 한다.
10. 자동 검증 결과와 실제 브라우저 수동 테스트 결과를 구분해서 기록한다.

## 6. 기술 및 설계
- HTML5, CSS3, JavaScript (별도 빌드·프레임워크 필요 없음)
- \`recipes.js\`: 32개 예시 레시피, 원본 기본 재료 및 한 줄 설명
- \`cooking-steps.js\`: 각 레시피 ID별 상세 단계 3개 이상
- \`logic.js\`: 재료 정규화, 교집합/차집합, 일치율 및 정렬
- \`app.js\`: 재료 관리, 추천 카드, 상세 조리법 토글, 검색·필터
- \`localStorage\`: 사용자의 재료 목록만 브라우저 내 저장
- \`tests/verify.cjs\`: 데이터 무결성·매칭·조리법 자동 검증
- 기존 Vercel \`report\` 프로젝트에 /fridge-chef/ 경로로 배포; 비용 보호를 위해 작업 브랜치 Preview 비활성화

## 7. 단계별 경과
### 1차 중간 점검
- 식재료 등록·삭제, 중복 방지, 자동 저장, 기본 화면을 구성했다.

### 2차 중간 점검
- 32개 예시 레시피와 추천 일치도·부족 재료·검색/필터를 구현했다.

### 최종 개선 (v2)
- 32개 레시피의 단계별 조리 방법을 보완했다.
- 하나의 요리 카드에서 펼쳐 보고 닫는 형태로 UI를 개선했다.
- 회귀 테스트에 상세 조리법의 단계 수·문구·데이터 무결성 검사를 추가했다.
- 변경 이유와 구현/검증 증거를 제출 파일과 발표자료에 기록한다.

## 8. 이번 범위에서 제외
회원가입, 서버·DB 동기화, 생성형 AI 조리법 생성, 사진 인식, 식품 안전성/알레르기 자동 검증, 영양 계산, 식재료 수량·유통기한 자동 관리 등은 제외한다.

**주의:** 표시된 재료 일치도는 정적 예시 데이터의 *기본 재료* 기준이며 실제 조리 가능성이나 식품 안전을 보증하지 않는다.

## 9. 향후 계획
- 실제 PC·모바일 브라우저에서 재료 입력/저장 및 상세 조리법 토글을 최종 확인한다.
- 실제 사용자 의견을 별도로 수집해 조리량·기본 양념·한 끼 인원 수 안내의 수요를 확인한다.
- 필요 시 레시피 범위 및 편의 기능을 확대한다.

## 10. 변경 이력
- **v1 · 2026-10-10:** 재료 관리, 32개 예시 레시피 매칭, 부족 재료 안내를 MVP 범위로 확정.
- **v2 · 2026-10-10:** 진행 중 제기된 '단계별 상세 조리법' 개선 요청을 반영해 모든 레시피에 접이식 3단계 조리 설명을 추가. 기존 핵심 목표 3개는 유지. v1 원문은 \`plan-v1.md\`에 보존.
