# 🥕 Fridge Chef — 냉장고 파먹기

냉장고에 남은 재료를 입력하면 **예시 레시피와 비교해 요리 후보를 추천**하고 **부족한 재료를 표시**하는 정적 웹앱.

- 작성자: limheejae
- ALEPH Premium 과제
- 배포: 최종 제출 단계까지 보류 (기존 Vercel report 사용)
- 작업 브랜치: feat/fridge-chef
- 계획 정본: [plan.md](plan.md)

## 실행

빌드·서버·계정·API 키 필요 없음. \`index.html\`을 직접 열면 된다. 파일을 웹서버에서 제공해도 동작한다. 재료 목록은 사용 중인 브라우저에만 저장된다.

## 기능
1. 재료 추가·삭제·중복 검사·로컬 저장
2. 보유 재료 비율에 따른 예시 레시피 추천
3. 레시피별 필요한 재료 / 부족한 재료 분리

- 레시피는 예시 데이터이며 양념·알레르기·위생을 자동으로 보증하지 않는다.
- 브라우저 저장 공간을 삭제하면 재료 목록도 지워진다.
- 입력 데이터는 서버로 전송되지 않는다.

## 테스트

Node.js가 있다면 \`node tests/verify.cjs\`로 순수 매칭 로직과 데이터 무결성 검사를 실행한다. 브라우저 사용성·접근성은 따로 수동으로 확인해야 한다.

## 점검 기록

- 1차: 재료 관리·저장
- 2차: 레시피 추천과 부족한 재료
- 최종: 모바일·빈 상태·오류 처리·배포 확인

실제 점검 수행 여부와 결과는 별도 기록한다.
