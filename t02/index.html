PC 경계 검사

아직 실행하지 않음
  • 1366×768 / 1920×1080: 조작 영역 잘림·가로 넘침 확인
  • 1초 안 같은 핵심 입력 10건: 이벤트당 입력 처리 수가 정확히 1 증가하는지 확인
  • 창 크기 변경: 현재 판 진행도와 조작 유지
  • 포커스 이탈/복귀: 이탈 중 자동 일시정지, 복귀 뒤 같은 판 재개
  • 수동 일시정지: 시간·문 상태 진행 없음, 재개 뒤 이어짐
  • 10분 연속 실행: 조작 가능 여부와 DevTools 빨간 오류 0건 확인

10분 실행과 두 기준 해상도는 실제 브라우저에서 마지막으로 확인해야 합니다.
