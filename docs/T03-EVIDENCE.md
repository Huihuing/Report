## 카드 3 — 극단 입력 12건

| # | 검사 입력 | 예상 | 기록 |
|---:|---|---|---|
| 1 | 긴 한글 문장 | 글자 유실 없이 줄바꿈 | **수정 전 FAIL → 수정 후 PASS** |
| 2 | 한글 + English + 123 | 혼합 문자 보존 | PASS |

| 4 | 😀🚀✨ 이모지 포함 | grapheme 단위 보존 | PASS |
| 5 | 빈 문구 | 이미지 유지, 글자 없음 | PASS |
| 6 | 세로 이미지 | 중앙 cover 잘림 | PASS |
| 7 | 가로 이미지 | 중앙 cover 잘림 | PASS |
| 8 | 투명 PNG | 투명 영역 합성 | PASS |
| 9 | X=5% 짧은 문구 | 왼쪽 위치 반영 | PASS |
| 10 | X=95% 짧은 문구 | 오른쪽 위치 반영 | PASS |
| 11 | 18px | 최소 크기 유지 | PASS |
| 12 | 96px | 최대 크기 유지 | PASS |

대표 결함: 카드 1 버전은 줄바꿈 없이 각 줄을 `slice(0, 60)`으로 잘라 긴 문장의 60자 이후가 사라졌다. 같은 긴 한글 입력을 현재 버전의 canvas 폭 기준 grapheme 줄바꿈으로 다시 검사해 전체 문구를 여러 줄로 보존하도록 수정했다.

잘못된 이미지 파일은 새 이미지가 검증·디코딩을 끝내기 전 기존 `editor.image`를 바꾸지 않으므로 기존 편집 내용이 유지된다.

## 카드 4 — 템플릿 CRUD

템플릿은 안정된 문자열 ID와 함께 localStorage 키 `t03-card-templates-v1`에 저장한다.

- 생성: 현재 문구·X/Y·크기·색·화면비 저장
- 불러오기: 선택 템플릿 설정을 편집기에 적용
- 수정: 배열 위치가 아니라 ID를 찾아 현재 설정으로 교체
- 삭제: ID가 같은 항목만 제거
- 새로고침: localStorage에서 다시 읽어 목록 구성
- 검사용 템플릿 3개 생성 버튼 제공

## 카드 5 — JSON 가져오기

| 입력 | 예상 | 처리 |
|---|---|---|
| 정상 version 1 + templates 배열 | 템플릿 복원 | 전체 검증 후 저장 |
| 문법 손상 JSON | 거부 + 기존 유지 | JSON.parse 실패 시 저장 안 함 |
| 필수 항목 누락 | 거부 + 기존 유지 | 모든 항목 검증 후에만 저장 |

## 완성 이미지 3개와 권리

공개 화면에서 브라우저 canvas로 다음 3개 PNG를 직접 생성한다.

1. 1:1 BUILD / TEST
2. 4:5 MAKE IT CLEAR
3. 9:16 ONE STEP

세 이미지는 외부 원본·로고·사진·캐릭터를 사용하지 않은 **본인 제작 기하학 이미지**이다. canvas의 PNG 인코더가 새 픽셀 파일을 만들기 때문에 원본 이미지의 EXIF/GPS 위치 메타데이터를 포함하지 않는다.

## 공개 안전

- 공개 화면에 전화번호·개인 이메일·상세 주소 등 개인정보를 넣지 않음.
- 코드와 문서에 API Key·Token·Password·Cookie·비밀 환경변수 원문을 넣지 않음.
- 사용자 업로드 이미지는 서버로 전송하지 않고 현재 브라우저에서만 처리함.
