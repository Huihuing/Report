# T02 전체 카드 검사 기록

검사 기준일: 2026-10-07  
결과물: https://report-huihuing.vercel.app/t02/

## 카드 1 — 30초 핵심 규칙

- 행동: 목표 색과 같은 왼쪽/오른쪽 문 선택.
- 성공: 현재 난이도의 관문을 30초 안에 모두 통과.
- 실패: 오답 또는 30초 시간 종료.
- 상태: 시작 전 / 플레이 중 / 일시정지 / 성공 / 실패.
- 다시 시작: 진행도·시간·문·입력 수를 새 판 기본값으로 초기화.
- 키보드: ←/A, →/D, P.
- 마우스: 왼쪽·오른쪽 문 버튼과 시작/재시작/일시정지 버튼.

## 카드 2 — PC 경계 검사

### 구현한 경계 처리

- 반응형 CSS로 620px 이하에서도 조작 버튼을 두 열로 유지하고 HUD를 재배치한다.
- resize 이벤트에 게임 상태를 다시 만들지 않으므로 창 크기 변경이 현재 진행도·시간·문 상태를 초기화하지 않는다.
- window blur 또는 document hidden 시 현재 남은 시간을 저장하고 자동 일시정지한다.
- focus/visible 복귀 시 자동 일시정지였던 경우에만 같은 남은 시간으로 재개한다.
- 수동 P/일시정지는 deadline 대신 remainingMs를 보존하므로 정지 중 시간이 진행되지 않는다.
- keydown listener는 한 번만 등록하고 event.repeat를 무시한다.
- 공개 화면의 "1초 내 동일 입력 10건 자체검사"는 실제 arena keydown 경로로 ArrowLeft 이벤트 10건을 보내고 diagnostic round를 이용해 입력 처리 10회·진행 10회를 확인한다.

### 실제 브라우저에서 최종 확인할 항목

- [ ] 1366×768: 조작 영역 잘림 0, 가로 넘침 0.
- [ ] 1920×1080: 조작 영역 잘림 0, 가로 넘침 0.
- [ ] 자체검사 버튼 결과: PASS · 10건 → 10회 처리 · 1000ms 미만.
- [ ] 창 크기 변경 뒤 현재 게임 상태/조작 유지.
- [ ] 포커스 이탈/복귀 뒤 같은 판 유지.
- [ ] 일시정지 중 시간·진행 정지, 재개 뒤 이어짐.
- [ ] 10분 연속 실행 뒤 조작 가능.
- [ ] 10분 연속 실행 뒤 DevTools Console 빨간 오류 0건.

## 카드 3 — 10회 전후 난이도 비교

변경하는 값은 **필요 관문 수 하나**뿐이다.

- 변경 전: 8문
- 변경 후: 10문
- 고정: 제한시간 30초, 좌우 조작, 색 2개, 오답 즉시 실패, 시간 종료 실패.

각 완료 판은 결과·소요 시간·실패 원인을 localStorage에 자동 기록하며 각 구간 최대 10회까지만 저장한다. 20회가 모두 쌓인 뒤 최종 8문 또는 10문을 선택하면 다음 통계를 이용해 이유 문장을 자동 구성한다.

- 각 구간 성공률
- 성공 판 소요 시간 중앙값
- 가장 반복된 실패 원인

### 실제 플레이 기록

- [ ] 변경 전 8문 10회 완료.
- [ ] 변경 후 10문 10회 완료.
- [ ] 최종 난이도 선택 저장.
- [ ] 선택 이유가 20회 기록의 성공률/중앙값/반복 실패 원인과 연결됨.

**주의:** 실제 사람이 플레이해야 하는 20회 기록을 생성했다고 가정하거나 임의 값으로 채우지 않는다.

## 카드 4 — 저장과 손상 복구

### 새 판에서 초기화되는 값

- 현재 진행도
- 남은 시간
- 현재 좌/우 문과 목표 색
- 현재 판 입력 처리 수
- 일시정지 상태

### 재접속 뒤 보존되는 값

- 총 완료 플레이 수
- 성공 수
- 최고 통과 관문 수
- 8문/10문 실험 기록
- 최종 난이도와 선택 이유
- 효과 줄이기 설정

저장 키: `t02-gate-sprint-save-v2`

읽기 과정에서 다음을 검사한다.

1. 저장값 없음 또는 빈 문자열 → 선언한 기본값으로 시작.
2. JSON 문법 손상 → 예외를 잡고 기본값으로 시작.
3. 구조/타입/범위 손상 → 전체 저장을 사용하지 않고 기본값으로 시작.
4. 정상 데이터 → 실험 기록을 구간별 최대 10개로 제한해 복원.

손상 복구 시 게임 자체는 중단되지 않으며 화면의 저장 복구 상태에 "기본값" 또는 "손상 복구"가 표시된다.

## 카드 5 — 효과와 선택권

선택한 효과 사건은 **게임 최종 성공**이다.

- 성공 상태에 도달했을 때만 arena에 짧은 success pulse 클래스를 적용한다.
- 실패·일시정지·일반 정답 통과에서는 이 효과를 실행하지 않는다.
- 헤더의 "효과: 켬/줄임" 버튼을 누르면 `data-motion="reduced"`가 즉시 적용되고 현재 성공 효과도 제거한다.
- reduced 상태는 localStorage에 보존한다.
- OS `prefers-reduced-motion` CSS도 함께 지원한다.

## 공개 안전

- 공개 화면과 문서에 전화번호·개인 이메일·상세 주소 같은 개인정보를 넣지 않았다.
- 새 T02 변경 커밋에는 API Key, access token, private key 등 비밀값 원문을 넣지 않았다.
- 외부 이미지·음원·캐릭터 없이 도형과 글자만 사용한다.
