## 카드 3 — 두 기준 화면

첫 화면에 `소개 / 활동 / 근거` 세 블록을 별도로 배치하고, 기존의 큰 히어로 타이포·과도한 상하 여백을 축소했다. `main { overflow:hidden }`은 제거해 가로 넘침을 숨겨 통과시키지 않도록 했다.

현재 연결 도구로는 실제 Chromium viewport 캡처를 실행할 수 없으므로 아래 두 항목은 제출 직전 실제 브라우저에서 최종 확인한다.

- [ ] 1366×768: 스크롤 전 소개·활동·근거가 모두 보이고 document scrollWidth가 viewport 폭과 같다.
- [ ] 1920×1080: 스크롤 전 소개·활동·근거가 모두 보이고 document scrollWidth가 viewport 폭과 같다.

## 카드 4 — 링크·키보드·제목·명암·콘솔

### 구조 검사

- 제목 구조: H1 1개 뒤 각 구역 H2, 카드 내부 H3 순서로 구성해 단계를 건너뛰지 않는다.
- 주요 상호작용은 native `a`, `button`, `details/summary`를 사용한다.
- T02/T03 근거 링크와 과제 링크는 동일한 공개 도메인의 실제 경로를 사용한다.
- 일반 본문 대비의 최소 조합을 계산했다.
  - Light muted #66645f / #f4f1ea = 약 5.24:1
  - Light muted #66645f / #fffdf8 = 약 5.81:1
  - Light accent text #8b240f / #f4f1ea = 약 7.90:1
  - Dark muted #aaa69c / #11110f = 약 7.78:1
  - Dark muted #aaa69c / #1a1916 = 약 7.24:1
  - Dark accent text #ffb5a3 / #11110f = 약 11.15:1
- 모두 일반 글자 기준 4.5:1 이상이다.

### 발견한 실제 결함과 수정 전후

1. **첫 화면 근거 부족**
   - 수정 전: 큰 히어로 뒤에 관심/근거가 내려가 있어 1366×768 첫 화면 기준을 충족하기 어려웠다.
   - 수정 후: 히어로 크기와 여백을 줄이고 첫 화면에 소개·활동·근거 3블록을 직접 배치했다.

2. **작은 화면 내비게이션 숨김**
   - 수정 전: 840px 이하에서 `nav { display:none }`이라 키보드 사용자가 헤더의 구역 링크를 순서대로 탐색할 수 없었다.
   - 수정 후: 작은 화면에서도 nav를 유지하고 가로 스크롤 가능한 키보드 링크 행으로 변경했다.

3. **움직임 선택권이 OS 설정에만 의존**
   - 수정 전: `prefers-reduced-motion`만 지원해 페이지 안에서 직접 움직임을 줄일 수 없었다.
   - 수정 후: 헤더에 Motion/Reduced 버튼을 추가해 smooth scroll과 transition을 직접 줄일 수 있게 했다.

추가로 localStorage 접근이 제한된 브라우저에서 예외가 전체 스크립트를 멈추지 않도록 get/set을 try/catch로 보호했다.

### 콘솔

- 정적 JS 구조와 공개 HTML 배포는 확인했다.
- [ ] 제출 직전 실제 브라우저 DevTools Console에서 빨간 오류 0건을 최종 확인한다.

## 카드 5 — 상호작용·움직임·비밀값

- 프로젝트 필터는 마우스 클릭과 native button 키보드 Enter/Space로 실행된다.
- EVIDENCE 영역의 `details/summary`는 소개 내용과 직접 연결된 펼치기 상호작용이며 마우스·키보드로 동작한다.
- Motion/Reduced 버튼으로 페이지 내 움직임을 줄일 수 있다.
- 공개하지 않기로 한 전화번호·개인 이메일·상세 주소를 T01 공개 화면에 넣지 않았다.
- Git 기록 30개를 두 구간으로 나눠 `ghp_`, `github_pat_`, `sk-`, AWS/Google 키 형태, private key, 값이 포함된 password/token/secret 패턴을 검사했으며 일치 항목은 0건이었다.

1. 1366×768 첫 화면과 가로 넘침.
2. 1920×1080 첫 화면과 가로 넘침.
3. DevTools Console 빨간 오류 0건.
