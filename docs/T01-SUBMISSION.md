# T01 제출 준비

## 결과물

- 결과물 URL: https://report-huihuing.vercel.app/
- 소스 URL: 제출 직전 최신 40자리 full commit URL을 사용한다.

## 재현·통과 확인 4가지

1. **어디로 가나요:** 공개 결과물 URL의 첫 화면으로 이동합니다.
2. **3단계 이내 무엇을 하나요:** 첫 화면의 소개·활동·근거를 확인 → EVIDENCE 영역에서 작업 흐름을 펼치거나 프로젝트 필터를 조작 → T02/T03 공개 근거 링크를 엽니다.
3. **무엇이 보이면 통과인가요:** 소개·활동·근거가 확인되고, 마우스와 키보드에서 상호작용이 동작하며 공개 근거 링크가 로그인 없이 열립니다.
4. **안 될 때 무엇이 보이나요:** 첫 화면 핵심이 잘리거나 가로 스크롤이 생기고, Tab/Enter/Space로 상호작용할 수 없거나 근거 링크가 열리지 않으면 실패입니다.

## AI와 내 판단 3줄

1. **AI에게 맡긴 일:** 한 페이지 구조·반응형 CSS·공개 근거 카드·접근 가능한 상호작용·대비/비밀값/제출 기준 점검과 수정 구현을 맡겼습니다.
2. **직접 판단한 일:** 누구에게 무엇을 보여줄지, 공개/비공개 범위와 세 가지 소개 근거, 공개 권한이 불분명한 프로젝트 자료를 노출하지 않는 기준을 직접 결정했습니다.
3. **AI 제안을 따르지 않은 일:** 모든 프로젝트 저장소와 스크린샷을 추가하는 방식은 과제 필수 조건이 아니고 공개 권한 문제도 있어 사용하지 않고, 공개 가능한 T02·T03 결과물과 관찰 가능한 결과 문장을 근거로 사용했습니다.

## 카드별 대응

- T01-C01: 결과물은 기존 report Vercel 공개 도메인, 소스는 공개 GitHub full commit URL 사용.
- T01-C03~C05: HERO 목적 문장 + SCOPE 공개/비공개 3개 이상.
- T01-C06~C09: EVIDENCE 카드 3개에 상황·행동·결과와 T02/T03/SCOPE 근거 연결.
- T01-C10~C12: 첫 화면에 소개·활동·근거를 배치하고 overflow 숨김을 제거. 실제 1366×768/1920×1080 최종 수동 확인 필요.
- T01-C13: 모든 페이지 내부 링크와 T02/T03 공개 경로 확인.
- T01-C14: 링크·버튼·summary를 native focusable 요소로 구성.
- T01-C15: H1 → H2 → H3 구조 유지.
- T01-C16: 주요 일반 텍스트 색 조합이 최소 약 5.24:1 이상.
- T01-C17: docs/T01-EVIDENCE.md에 실제 결함 3건 수정 전/후 기록.
- T01-C18: 실제 DevTools Console 빨간 오류 0건 최종 수동 확인 필요.
- T01-C19~C21: 프로젝트 필터 및 EVIDENCE details 상호작용을 마우스와 키보드로 제공.
- T01-C22: Motion/Reduced 버튼 및 prefers-reduced-motion 지원.
- T01-C23: 공개 화면에 전화번호·개인 이메일·상세 주소를 포함하지 않음.
- T01-C24: Git 기록 30개의 대표 비밀값 패턴 검사 결과 일치 0건.
- T01-C25~C26: 이 문서의 4줄/3줄 형식으로 구분.
