## 재현·통과 확인 4가지

1. **어디로 가나요:** 공개 결과물 URL의 T05 비교 보고서와 연결된 T04 공개 검사 화면으로 이동합니다.
2. **3단계 이내 무엇을 하나요:** A/B 측정표 확인 → T04의 manifest 17파일 전체 검사 실행 → 인수인계·고정 검사·A/B 결과 링크를 확인합니다.
3. **무엇이 보이면 통과인가요:** 고정 검사 10개가 유지되고 AI A 9/10에서 AI B 10/10으로 이어지며, T04 정본 package 검사가 17 PASS / 0 FAIL이고 A/B 시간·호출·오류회차·통과수가 함께 표시됩니다.
4. **안 될 때 무엇이 보이나요:** 검사 수가 10개가 아니거나 검사 기대값이 바뀌고, package 검사에 FAIL이 남거나 A/B 작업 순서·인수인계·측정값·버전 근거가 빠지면 실패입니다.

## AI와 내 판단 3줄

1. **AI에게 맡긴 일:** T04 package 무결성 검사 개선, 고정 검사 실행, 인수인계 재현, A/B 결과 대조와 공개 비교 보고서 정리를 맡겼습니다.
2. **직접 판단한 일:** 검사 10개와 공통 사용 상한을 작업 전에 고정하고, AI B에는 이전 대화 전문 없이 저장소와 인수인계 문서만 제공하는 방식을 선택했습니다.
3. **AI 제안을 따르지 않은 일:** 검사 삭제·완화나 기대값 변경으로 결과를 맞추는 방식은 사용하지 않고, 동일한 고정 검사 10개를 끝까지 유지했습니다.
