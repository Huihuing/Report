## 개선 기능

T04 "오늘의 진짜 정보판"에 **관측 지연도 배지**를 추가한다.

사용자는 실제 원천 관측 시각(source_observed_at)과 조회 시각(fetched_at)의 차이를 보고 다음 상태를 확인할 수 있어야 한다.

- 최신: 0분 이상 15분 이하
- 지연: 15분 초과 60분 이하
- 오래됨: 60분 초과
- 시각 오류: 원천 시각이 조회 시각보다 미래
- 알 수 없음: 필수 시각이 없거나 해석할 수 없음

이 개선은 기존 T04의 actual live record, 합성 fixture, stale/error 상태 의미를 바꾸지 않는다.
