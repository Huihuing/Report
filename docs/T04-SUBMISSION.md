## 재현·통과 확인 4가지

1. **어디로 가나요:** 공개 결과물 URL의 ‘오늘의 서울 기온’ 정보판으로 이동합니다.
2. **3단계 이내 무엇을 하나요:** 실제 값 다시 조회 → 합성 실패 버튼 하나를 눌러 stale 상태 확인 → ‘다시 시도 · T04-RECOVER-D2’를 눌러 복구를 확인합니다.
3. **무엇이 보이면 통과인가요:** 실제 값·단위·출처·출처 시각·조회 시각·Asia/Seoul이 보이고, 실제 KST 날짜 기록 2건과 어제 대비 -5.1°C가 표시되며, 합성 실패 뒤 마지막 정상값 105가 stale로 유지되고 복구 뒤 fresh/none·행 2건·120 pt로 돌아옵니다.
4. **안 될 때 무엇이 보이나요:** 실제 값의 출처/시각이 없거나, 실패 뒤 마지막 정상값이 사라지거나, 다섯 실패가 같은 오류로 표시되고 다시 시도 뒤 fresh/none으로 복구되지 않으면 실패입니다.

## AI와 내 판단 3줄

1. **AI에게 맡긴 일:** 공개 fixture package와 SHA-256 검증, 비밀키 없는 실제 데이터 호출, 일별 upsert·어제 대비 계산, 다섯 실패/stale/복구 상태와 제출 기준 구현을 맡겼습니다.
2. **직접 판단한 일:** 실제 값은 개인 위치가 아닌 서울 고정 좌표의 2m 기온으로 정하고, 실제 기록은 Asia/Seoul 날짜별로 정확히 두 날만 보존하며 합성 D1/D2를 실제 날짜 증거로 사용하지 않기로 결정했습니다.
3. **AI 제안을 따르지 않은 일:** 별도의 제안을 억지로 따르지 않은 사례는 없었고, 과제 계약이 실제 서로 다른 KST 날짜 2건을 요구해 합성값이나 과거값으로 둘째 날을 대신하지 않았습니다.
