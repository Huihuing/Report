## 처음 사용하는 사람의 세 행동과 합격 기준

1. 첫 화면에서 논문 제목과 도움 문장을 확인합니다. **합격:** list/set을 연구한 근거와 앱 사용 목적이 보입니다.
2. 크기 10,000, 조건 부재로 비교합니다. **합격:** 원자료 중앙값 list=64,935.154ns / set=18.132ns가 보이고, 순서가 중요하지 않다면 반복 조회에 set을 고려하도록 안내합니다. 첫 위치로 바꾸면 차이를 과장하지 않습니다.
3. 예시 입력 -1, 0, 9999, 999999, abc, 공백을 각각 실행합니다. **합격:** 앞의 3개는 해당 크기에서 부재/존재/존재, 999999는 부재, abc와 공백은 안내 문구가 나오고 페이지가 중단되지 않습니다.
