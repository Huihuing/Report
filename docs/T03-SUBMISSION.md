# T03 제출 준비

## 결과물

- 결과물 URL: https://report-huihuing.vercel.app/t03/
- 소스 URL: 최종 제출 직전 최신 40자리 full commit URL 사용

## 재현·통과 확인 4가지

1. **어디로 가나요:** 공개 결과물 URL의 짤·카드 스튜디오 첫 화면으로 이동합니다.
2. **3단계 이내 무엇을 하나요:** PNG/JPEG를 불러오기 → 1:1·4:5·9:16 중 하나를 고르고 문구를 편집하기 → PNG 저장 또는 템플릿/JSON 기능을 확인합니다.
3. **무엇이 보이면 통과인가요:** 이미지와 문구가 즉시 미리보기에 반영되고 저장 PNG가 같은 배치로 열리며, 템플릿 CRUD와 정상 JSON 복원이 유지됩니다.
4. **안 될 때 무엇이 보이나요:** 이미지가 사라지거나 저장 PNG 배치가 다르고, 잘못된 파일/JSON 뒤 기존 편집 또는 템플릿이 없어지면 실패입니다.

## AI와 내 판단 3줄

1. **AI에게 맡긴 일:** canvas 미리보기·PNG 저장, 화면비 전환, 긴 문구 줄바꿈, 템플릿 CRUD, JSON 검증과 제출 기준 점검 구현을 맡겼습니다.
2. **학생이 직접 판단한 일:** 짤·카드 제작 도구로 구성하고 1:1·4:5·9:16 비율, 사용자 템플릿 방식, 외부 저작물 없는 완성 이미지 구성으로 결정했습니다.
3. **AI 제안을 따르지 않은 일:** 과제별 별도 Vercel 프로젝트를 만들지 않고 기존 report 프로젝트 한 곳의 /t03/ 경로에서 운영하기로 했습니다.
